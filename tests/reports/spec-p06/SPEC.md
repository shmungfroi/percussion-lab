## Interface between the two builders
`notation.js` defines `window.Rudiments = { list: [{n, name, family}], svg(n, opts) -> string }` (40 entries, n = 1..40, names = current VIC_RUDIMENTS names; "Drag (Ruff)" may stay). SVG uses currentColor, viewBox-scaled, no external resources, readable at 360px wide (wrap long rudiments onto two systems or allow horizontal scroll inside its own box). index.html loads it with `<script src="notation.js"></script>` before the main script and shows `Rudiments.svg(n)` in the rudiment overlay; if `window.Rudiments` is missing, show a short notice. `scripts/build_single_file.py` inlines notation.js instead of the poster.
