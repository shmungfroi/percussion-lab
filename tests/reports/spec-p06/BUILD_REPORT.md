## Things to know

1. **Shared working folder.** Both builders worked in the same checkout. My P3 commit (`eaf7b12`) used `git add -A` as instructed and so picked up the other builder's unfinished `notation.js` and `tests/notation_preview.html`. I did not write or edit those files; their own later commits replaced the contents. From P4 on I staged my files by name. Their first P4 commit likewise carried my staged deletion of the poster image.
2. **Class-name clash, fixed on my side.** `notation.js` gives note groups the class `note`; the app's `.note` style (small grey text) turned note heads and sticking grey. `.notation svg *{color:inherit}` in `index.html` stops any app text colour reaching the drawing, and a test checks every SVG element's colour.
3. **Framed test is cross-origin.** The suite serves `/__frame.html` and opens it on `localhost` while the frame loads `127.0.0.1`, so the frame really has no clipboard, modals, print or downloads, as in the viewer.
4. **New README rule 7**: no `alert`/`confirm`/`prompt`, no bare `window.print()`, no download without a copy-and-paste fallback.
5. **Test stub.** `tests/stub_notation.js` is only served when the suite is run with `--stub` or when `notation.js` is absent. It was never committed as `notation.js`.
